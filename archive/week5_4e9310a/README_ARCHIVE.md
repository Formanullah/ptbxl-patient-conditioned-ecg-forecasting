# Week 5 implementation (archived)

Snapshot of the Week 5 pipeline as of commit `4e9310a`, moved here when the
project was rebuilt from scratch (decision log D1.0). Contents:
`src/`, `tests/`, `configs/`, `notebooks/`, `docs/`, `tools/`, `requirements.txt`,
`pyproject.toml`, the CI workflow and the generated `outputs/` and
`ptbxl_eda_outputs/` folders. The `outputs/` folder was previously at the project
root; references to it in `archive/legacy_2ad3e68/` now resolve here.

The code is unchanged and still expects to run from this folder's layout, with its
own `requirements.txt`. Its results (summarized in `docs/WEEK5_RESULTS.md`) used a
different protocol and must not be pooled with the rebuilt study. The Phase 0
feasibility report (`reports/phase0_feasibility/REPORT.md`, §7) explains why its
models did not beat a flat zero-line forecast.
